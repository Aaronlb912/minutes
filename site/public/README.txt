Minutes and ordinance search

Copy this whole folder into your website. Keep these files together:

  index.html
  styles.css
  app.js
  records.json
  README.txt

Put the folder in your public files, for example:

  your-site/minutes/

Then open /minutes/ on that site. Any static host works. You do not
need Node after the files are on the site.

Make it yours:

  1. Edit records.json, or open the page and use Add a record.
  2. Change This desk to your village name and phone.
  3. Download JSON and replace records.json if you edited in the browser.

The sample village in records.json is fake starter data.
